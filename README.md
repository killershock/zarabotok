# Заработок — учёт услуг и заработка

Мобильное приложение для Android и iPhone (PWA). Записывайте стоимость оказанных услуг — приложение считает
суммы за день, неделю, месяц и год, отдельно по каждому сотруднику. Работает офлайн, без регистрации.

## Возможности

- **Записи услуг** — дата, сотрудник, название услуги, цена, количество, заметка. За день можно добавить сколько
  угодно услуг.
- **Итоги** — день / неделя / месяц / год с переключением периодов стрелками и графиком динамики.
- **Сотрудники** — карточка каждого с суммами за день, неделю, месяц, год и за всё время.
- **Разбивка по сотрудникам** на главном экране: кто сколько заработал и доля от общей суммы.
- **Каталог услуг** — частые услуги с ценами подставляются в форму автоматически.
- **Записи** — поиск по услуге/сотруднику/сумме, фильтр по сотруднику, группировка по дням.
- **Автоматические резервные копии** — раз в месяц на телефоне, плюс облако (GitHub Gist) по желанию.
- **Экспорт** — CSV для Excel/Google Таблиц, JSON-копия, импорт на другом телефоне.
- **Установка на главный экран** — открывается как обычное приложение, работает без интернета.

## Быстрый запуск на компьютере

В папке `salary-app`:

1. Запустите `Запустить-на-компьютере.bat`
   (или `python -m http.server 8080` в терминале).
2. Откройте <http://localhost:8080>.

Проверка на телефоне в той же Wi‑Fi-сети: `ipconfig` → откройте `http://192.168.x.x:8080`.

## Публикация на GitHub Pages (рекомендуется)

Нужен аккаунт GitHub. Всё остальное скрипт сделает сам: создаст репозиторий, загрузит файлы и включит Pages.

### 1. Создайте токен

1. Откройте <https://github.com/settings/tokens/new?scopes=repo&description=Zarabotok>.
2. В поле Note — любое имя (например, `Zarabotok deploy`).
3. Срок действия — на ваш выбор (можно 30 дней, после публикации токен можно отозвать).
4. Отметьте **только галочку `repo`** (она включает все подпункты).
5. Нажмите **Generate token** и скопируйте токен (`ghp_...`) — он показывается один раз.

### 2. Запустите публикацию

1. Дважды щёлкните `Опубликовать-на-GitHub.bat` в папке `salary-app`.
2. Вставьте токен в консоль (ввод не отображается) и нажмите Enter.
3. Имя репозитория можно оставить `zarabotok` — просто нажмите Enter.
4. Скрипт выведет ссылку `https://ВАШ-ЛОГИН.github.io/zarabotok/` и откроет её.

Первая сборка GitHub Pages занимает 1–2 минуты. Если ссылка сразу не открылась — подождите и обновите.

### 3. Установите на телефон

- **Android (Chrome):** откройте ссылку → меню ⋮ → **Установить приложение**.
- **iPhone (Safari):** откройте ссылку → **Поделиться** → **На экран «Домой»** → **Добавить**.

### 4. Отзовите токен (по желанию)

После публикации токен больше не нужен: <https://github.com/settings/tokens> → Delete. Обновлять приложение
можно, снова запустив скрипт с новым токеном.

> Если не хотите использовать токен — можно загрузить файлы вручную через веб-интерфейс GitHub
> (Add file → Upload files) и включить Pages в Settings → Pages. Понадобятся: `index.html`, `styles.css`,
> `app.js`, `manifest.webmanifest`, `sw.js`, папка `icons`, файл `.nojekyll`.

Альтернатива без GitHub: перетащите папку `salary-app` или ZIP на <https://app.netlify.com/drop> и получите
HTTPS-ссылку.

## Резервные копии

Приложение делает копии автоматически, без вашего участия.

### На телефоне

- При каждом запуске приложение сохраняет актуальную копию за текущий месяц в защищённое хранилище браузера
  (IndexedDB). Прошлые месяцы остаются как история — хранятся последние 12 месяцев.
- «Ещё → Резервные копии → История» — можно скачать любую копию в JSON или восстановить её одним нажатием.
- «Сохранить» — дополнительная копия вручную.
- На главном экране раз в месяц появляется напоминание скачать файл, если облако не подключено.

### Облако (GitHub Gist)

- В «Ещё → Резервные копии → Облачная копия GitHub» вставьте токен — приложение создаст **приватный** Gist
  и раз в месяц будет обновлять в нём файл `zarabotok-backup.json`.
- Копия обновляется при открытии приложения в новом месяце, а также кнопкой «Копировать».
- «Восстановить» загружает последнюю копию из GitHub и заменяет текущие данные (перед заменой текущее
  состояние сохраняется отдельной копией на телефоне).
- Токен хранится только на телефоне, отдельно от данных, и не попадает в экспортируемые файлы.

**Какой токен нужен для облака:** отдельный классический токен с галочкой `gist`
(<https://github.com/settings/tokens/new?scopes=gist&description=Zarabotok>). Он даёт доступ только к Gist.
Его можно отозвать в любой момент. Токен для публикации (`repo`) и токен для копий (`gist`) — разные вещи,
лучше не использовать один и тот же.

### Важно про «автоматически»

Приложение — веб-приложение (PWA). Оно не может работать, когда полностью закрыто, поэтому копия создаётся
**при следующем открытии** приложения в новом месяце (и при каждом запуске обновляется копия текущего месяца).
Если телефон потерялся сразу после месяца без запусков — облачная копия будет за последний месяц, когда
приложение открывалось. Для максимальной сохранности открывайте приложение хотя бы раз в месяц или нажмите
«Копировать» после важных изменений.

## Где хранятся данные

- Записи, сотрудники, услуги и настройки — в `localStorage` (ключ `zarabotok_v1`).
- Резервные копии — в IndexedDB (`zarabotok_backups`).
- Настройки облака (токен, id Gist) — в `localStorage` (ключ `zarabotok_cloud_v1`).

Данные не отправляются в интернет, кроме случая, когда вы сами подключили облачную копию GitHub: тогда JSON
с данными уходит в ваш приватный Gist через API GitHub.

Очистка данных сайта в браузере удалит и записи, и локальные копии. Скачанный JSON или облако помогут
восстановиться.

## Импорт и перенос

- **Экспорт JSON** — файл со всеми данными. Сохраните его в Telegram/почту/облако.
- **Импорт JSON** — добавляет данные к текущим, дубликаты записей (по id) не создаются.
- Для полного восстановления удобнее «История копий → Восстановить» или облачная копия: они заменяют данные.

## Ограничения и развитие

- Данные не синхронизируются между несколькими телефонами в реальном времени. Облачная копия — это резервная
  копия, а не совместная работа. Для синхронизации нужен сервер.
- Это PWA, а не приложение из App Store / Google Play. Устанавливается с сайта за 10 секунд, не требует
  модерации и обновляется автоматически.
- При необходимости проект упаковывается в нативный APK/IPA (Capacitor) для публикации в сторах.
- Расчёт зарплаты — сумма оказанных услуг сотрудника за период. Оклады, проценты, авансы и вычеты можно
  добавить отдельным шагом.
